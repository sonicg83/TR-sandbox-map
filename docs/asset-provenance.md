# 地图素材来源与限制

首版使用程序自绘的菱形地块、符号和配色；未复制 TravianZ 图片或代码。地图以 TravianZ 的游戏地图为视觉方向，但地貌和资源类型到素材的映射尚未验证，因此自绘地块仅为示意，不表示精确地貌。TravianZ 仓库提供 GPLv3 文件，个别资源的来源和可分发条件仍需核实后才能复用。


## 原创地貌图片（2026-11-18）

`trmap/static/assets/landscape/` 中的五张 PNG 使用 OpenAI 内置图像生成工具创建，以用户提供的游戏地图截图作为等距视角和自然色调的风格参考，并未复制游戏素材。文件名对应扫描 JSON 的 `static.landscape_type`：`Lake`（湖泊）、`Forest`（森林）、`Clay`（黏土坑）、`Hill`（丘陵）、`Vulcano`（火山，沿用数据中的拼写）。图片是用于辨识地貌的示意，不代表真实地形形状或资源分布；实际游戏中的视觉映射尚未验证。

生成提示词：等距策略地图独立透明素材，参考截图的俯视视角和自然色调，简洁、轮廓清晰，分别绘制湖泊、森林、黏土坑、岩石丘陵与火山；不含文字、界面、图框或地块底板。


## 绿洲资源标识（2026-11-18）

`trmap/static/assets/oasis/` 中的 `Lumber`、`Clay`、`Iron` 和 `Crop` PNG 使用 OpenAI 内置图像生成工具制作，分别表现三根圆木、三块红砖、三块铁矿石和三捆小麦，透明背景且未预绘圆环。生成提示词要求极简、清晰、等距地图风格；占领状态圆环由界面绘制。

绿洲底图采用地貌示意：木对应森林、泥对应黏土坑、铁对应丘陵、粮对应湖泊。多资源时按木、泥、铁、粮顺序选择第一个非零资源；完整数据仍保存在地块详情中。该映射为用户指定的显示规则，不代表实际地貌观察。


## 村庄人口等级示意（2026-11-18）

`trmap/static/assets/village/level1.png` 至 `level4.png` 使用 OpenAI 内置图像生成工具，以本项目原创森林素材作为风格参考制作。四幅图分别表示人口低于 100、100–399、400–999、1000 及以上的村庄；建筑和城墙仅为抽象等级示意，并非实际建筑观察。人口未知或观察冲突时不推定等级。
