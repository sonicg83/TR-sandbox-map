# 地图素材与缩放设计

- 村庄按已知人口划分：<100、100–399、400–999、≥1000；外观是圆形据点，依次增加建筑并强化城墙，新村为木墙和两座建筑。未知及冲突不推测等级。
- 绿洲以木、泥、铁、粮的顺序选择一种主图案，详情保留全部数据；无有效类型或冲突时不推测。
- 原创素材参考等距战略地图视觉，记录来源与生成过程。图案只表达抽象类型与人口档次，非真实建筑观察。
- 固定 100%、50%、10%；10% 不画绿洲图案，村庄是色点，当前沙盘方案中同坐标标记决定颜色，无标记深灰。保留未知和冲突提示。
- 左侧贴边工具栏：放大、缩小、原点归中；滚轮分档，以指针位置为缩放中心；按钮以视口中心为缩放中心，归中保留缩放。
- 视野查询必须处理 40000 地块上限；保留来源、观察时间和沙盘与观察的隔离。保持已有功能，记录地貌映射未验证。
