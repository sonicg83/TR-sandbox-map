# TRMap

TRMap 是一个基于 Travian 服务器地图数据的独立交互式战略沙盘。它将每日公开的村庄数据与扫描得到的地图地块数据结合，帮助用户观察战场布局、规划资源调度和分析战略方案。

## 项目目标

- 以可交互地图呈现村庄、玩家、联盟、空地、绿洲和地貌等已知信息。
- 导入每日地图数据及扫描结果，支持按需更新局部观察，并显示数据来源和时间。
- 提供独立于游戏的标记、路线、备注和方案，辅助静态规划与比较。
- 在数据充分且规则可验证的前提下，逐步提供变化对比、距离计算和战略分析。

TRMap 不实现游戏功能，不代表用户执行游戏操作。沙盘中的计划和计算是用户维护或估算的内容，不应被展示为服务器上的真实行动或未观察到的情报。

## 数据原则

服务器数据、扫描观察和用户创建的沙盘内容分别保存。数据应能追溯到服务器、赛季或开服轮次、来源和观察时间；未知、扫描失败及确认空置是不同状态。不同来源发生冲突时，按字段、来源和时间处理，不能仅凭缺失推断具体事件。涉及地图边界、距离及其他服务器规则时，应使用明确配置并以目标服务器样本验证。

## 参考项目

本地 `other_projects/` 为不纳入本仓库的参考资料：

- `mapdata`：下载并解析每日地图数据，可上传至 WPS 多维表。
- `travian-scan`：扫描地图地块，输出村庄地块、绿洲和地貌数据。
- `TravianZ-11`：社区开源游戏，可参考其地图呈现与坐标处理。

参考项目的代码和素材不能默认自由复制。复用前须核对对应文件的许可、来源和适用条件，并记录必要的归属信息；TravianZ 仓库包含 GPLv3 许可证，具体复用方案需单独核实。

## 当前状态

初版提供本地档案、数据文件导入、菱形地图、搜索与筛选、标记和路线。地块暂以自绘图形示意，尚未完成 TravianZ 素材授权及精确地貌映射，不能作为真实地图外观的还原。

## 本地运行

安装 Python 3.14 和 [uv](https://docs.astral.sh/uv/)，在项目目录执行：

```powershell
uv sync
uv run python main.py
```

在浏览器打开 `http://127.0.0.1:8000`。服务仅监听本机；停止终端中的进程即可退出。数据保存在本地 `data/trmap.sqlite3`，备份前请先停止服务并复制该文件。

创建服务器档案后，分别选择 `map.sql` 或 `travian-scan` 的聚合 JSON 导入。导入前请确认文件属于当前服务器和赛季，程序无法自行验证其归属。观察时间可留空：不确定时应留空，系统不会用导入时间冒充观察时间。导入只读取和解析 SQL 文件，不执行文件里的语句。一次性扫描可能耗时较长，若无法确认其统一观察时间，应留空。

同一来源的多个观察时间未知或相同时存在不同值，会在地块详情显示冲突；文件没有提到的坐标不视为空地。不同来源的数据分别显示，不能据此假设它们是在同一时间观察到的。边界环绕、扫描任务、自动同步及完整历史回放暂未实现。

文件格式和操作步骤详见 [地图数据导入说明](docs/data-import.md)。

测试：`uv run pytest -q` 和 `node --test tests/test_map_geometry.mjs`。
